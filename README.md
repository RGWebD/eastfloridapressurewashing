# East Florida Pressure Washing

Static sales preview by RGWebD. The site is plain HTML, CSS, and JavaScript at the repository root, so GitHub Pages can serve it with no build step.

- `index.html` — preview website
- `logo.html` — logo showcase
- `assets/logo/` — badge, horizontal and stacked lockups (light and dark), plus PNG exports
- `assets/img/` — resized WebP photos used on the site
- `source-assets/` — original photos and the previous logo; the pages do not load these files

Open `index.html` in a browser, or publish the repository root with GitHub Pages.
